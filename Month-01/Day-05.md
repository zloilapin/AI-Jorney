# Day 5: The `requests` Library - Python's Web Courier

## 🧠 What I Learned Today
Today, I transitioned from HTTP theory to actual Python code implementation. I learned how scripts physically communicate with the internet.
* **Python Libraries (`import`):** I learned that base Python uses external packages called "libraries" to gain new capabilities. The `import` command brings these tools into the script.
* **The `requests` Module:** This is the industry-standard library for making HTTP requests in Python. It acts as the "courier" for the script.
* **Constructing the Call:** I successfully combined my knowledge of variables, dictionaries, and HTTP methods to write the core logic of an AI automation script. I used `requests.post()` to send my isolated `headers` and `body` variables to an external API endpoint.
